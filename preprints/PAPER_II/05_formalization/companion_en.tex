\textbf{Technical companion to Papers I and II.}\\\textbf{Preprint 1.0 — 6 November 2026.}

This companion identifies the proof sources used for the two manuscripts. It also records how to distinguish their verification claims. The spectrum theorem is a theorem for all sufficiently large admissible profiles. The class-size characterization is a theorem for every positive profile; its proof includes an explicit finite table calculation.

The principal result of Paper I is cdr\_type\_spectrum. The auxiliary cdr\_eventually calls T on the complete host (Proposition 3.2). Paper II proves existence at every order. The written proof invokes CDR 1999 for its last finite cases; the archived formal proof instead checks explicit multiplication tables.

\subsection{5. From the formal statements to the two proofs}\label{from-the-formal-statements-to-the-two-proofs}

\textbf{Existence at large order.} In Asymptotic.lean, cdr\_eventually chooses the threshold before the three class sizes. The complete graph on the partition supplies the host. The proof takes the maximum of 400 and the threshold returned by main\_theorem\_T with parameters \((1/32,4,6)\). It passes the four proofs cdr\_H1, cdr\_H2, cdr\_H3' and cdr\_H4 to T. The last conversion, realises\_of\_decomposition, turns the triangle decomposition into the required Steiner system. This proves the auxiliary existence statement of Proposition 3.2.

The four host checks can be read separately. \textbf{H1} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Host.\allowbreak{}lean}) · \textbf{H2} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Lattice.\allowbreak{}lean}) · \textbf{H3/H4} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Hinge.\allowbreak{}lean}) · \textbf{Proposition 3.2} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Asymptotic.\allowbreak{}lean}).

\textbf{Exact counts.} Corners.Necessary starts from an actual system and counts the pairs through one vertex. Corners.Spectrum packages the resulting two tests in ExactNec. Its sufficiency proof first tests the planting inequality in the original order. If it holds, Graphs constructs the internal degrees, Plant assigns the third vertices and Lower assembles the minority packing. Residual computes the remaining neighbor counts; Seed3 and Lattice3 establish the fractional and integer conditions on those edges. LowerT calls T with only the majority types. If the test holds after swapping the classes, Symmetry transports the construction back. If both tests fail, large\_counts\_R puts all six counts in the range of Exact.Final, which calls T+ and switches the reserved trades. The criterion and its converse refer to the same integer \(t\).

The proof of the exact spectrum uses the following intermediate certificates. \textbf{Degree sequence} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Corners/\allowbreak{}Graphs.\allowbreak{}lean}) · \textbf{Planting} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Corners/\allowbreak{}Plant.\allowbreak{}lean}) · \textbf{Integer lattice} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Corners/\allowbreak{}Lattice3.\allowbreak{}lean}) · \textbf{Mass correction} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Exact/\allowbreak{}Final.\allowbreak{}lean}) · \textbf{Case split} (\texttt{CDRBicolour/\allowbreak{}Absorption/\allowbreak{}Corners/\allowbreak{}Spectrum.\allowbreak{}lean}).

\textbf{All orders.} Characterization exposes the implication in each direction. For sufficiency, Universal sorts the classes and uses strong induction on their sum. Descent.L165 combines smaller systems at composite orders. Master.Equitable supplies five block types by successive edge colorings. For the gap-two family the packing leaves a graph on the last class; L183.P2 proves it can be colored with the required number of colors and L184.Assembly attaches the missing pairs. Base.Cover identifies the inputs that remain below 5059. A successful check of an example establishes a single realization. The separate coverage and induction theorems explain how those individual statements enter a universal conclusion.

The project ledger records the successive constructions. For the proofs described here the controlling sources are the frozen theorem statements and imports. The development notes on the endpoints are best read alongside Corners.Spectrum, which assembles both ends and the interior. GATES · Corner constructions.

\subsection{6. Reproducing one witness and reading the audit}\label{reproducing-one-witness-and-reading-the-audit}

The witness files encode two base-64 digits for each unordered pair in lexicographic order. Decode the third point, check that it differs from both endpoints, and look up each of the other two pairs. Both lookups must return the missing endpoint. Finally check that the three labels take exactly two values. For the smallest table the output is \(012,034,056,136,145,235,246\), precisely the seven blocks of Figure 1 in Paper I. Running the same checks over the 49 files tests 1,203,132 pairs. They can be run independently of Lean.

The first command checks the package, the recorded Lean audit and the finite witnesses from the publication repository. To repeat the declaration queries, extract the shared archive, restore the compiled project environment, and run the last two commands from its root. These queries read existing objects. A source-only installation must first acquire the pinned dependencies and compile them.
