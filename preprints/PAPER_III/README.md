# Paper III - Prescribed block types and abundance

Preprint 1.0. Juan Pablo Traverso Gianini. DOI: https://doi.org/10.5281/zenodo.24201563

[English manuscript](01_manuscript/prescribed_en.pdf) | [Manuscrito en español](01_manuscript/prescribed_es.pdf)

[Companion EN](05_formalization/companion_en.pdf) | [Companion ES](05_formalization/companion_es.pdf)

[Lean source archive](05_formalization/CDRIII_Lean_v1.0.zip) | [Release audit](02_validation/v1.0/AUDIT_RESULT.json)

The paper treats exact interior type matrices, sparse completion, optimal leading
counting coefficient 1/6, Pasch diversity with fixed exact types, and eventual
existence for each fixed number of at least four colors. The arithmetic threshold
is ineffective. It extends CDR Papers I-II using T and T+ of Triangle decompositions III.

The 1,306 project modules compiled in an isolated source-bound reconstruction. Only
pinned external Mathlib ecosystem caches were reused. Four endpoint audits contain
only propext, Classical.choice and Quot.sound. Complete source, object and configuration
hashes and retained diagnostics accompany the release. This internal release audit
is not journal peer review or a new specialist review of all external analytic proofs.

From the series repository root, run `python scripts/verify_cdr_iii.py`.
The source ZIP includes the portable Lean tree and upstream licenses. Manuscripts,
companions and original figures use CC BY 4.0. This directory contains only the
first public preprint edition and its supporting evidence.
