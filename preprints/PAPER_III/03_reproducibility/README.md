# Reproducing the paper selection

The semantic sources are `01_manuscript/prescribed_en.md` and its Spanish
translation `01_manuscript/prescribed_es.md`.
The formal source selection is under the top-level `lean/` directory.

## Source and packaging checks

From the project directory:

```text
python scripts/verify_package.py
```

This verifies every copied source hash, the import closure and the four
canonical endpoint axiom records. It does not run a fresh full Lean build.

## Independent full reconstruction

Install the toolchain specified by `lean/lean-toolchain`, then from `lean/`:

```text
lake update
lake exe cache get
lake build CDRIII
lake env lean checks/Axioms.lean
```

Mathlib is pinned at `c55e6e786f49471c72fbddbec5415808896aec1e`.
The committed package manifest pins its ecosystem. `lake update` resolves
only the Mathlib requirement and its ecosystem; every selected non-Mathlib
proof is already present as a local library. Preserve the manifest if the
resolver proposes unrelated dependency updates. Network access is needed
for the pinned external packages and their caches.

The isolated reconstruction is complete. The selected 1,305 dependency modules
and `CDRIII` were rebuilt, with only pinned external Mathlib caches reused.
The four endpoint queries passed. Sources and final configuration were checked
before and after the run; object hashes and full logs accompany the freeze.
The final resource setting was `LEAN_NUM_THREADS=1`. The committed per-library
options preserve the original provider settings. No mathematical source changed.

## Origin and extraction

`scripts/export_lean.py` records the originating checkout, Git HEAD, exact
current source hashes and original cached object hashes. The originating
checkout contains uncommitted work, so the Git HEAD alone does not identify
the source selection. `SOURCE_MAP.json` is the byte-level identity record.

The script is for the author's originating Windows installation. Running it
elsewhere is unnecessary: all selected sources are included. Reproduction
of this delivered selection uses the portable `lean/` project above.

No old development drafts, pending descent modules, credentials or `.git`
directories are copied. Object files in the local `.lake/` are ignored by
Git and are not part of the source package.

## Review PDFs, version 1.0

The authoring commands are `python scripts/typeset_manuscripts.py` and
`python scripts/review_manuscripts.py`, run from the repository root. The
former uses the locally cached Pandoc/Tectonic runtime and the existing CDR
Paper II template; its absolute runtime paths are author-local. It converts
only the body and preserves the series front matter. The delivered TeX/PDF
files can be inspected without that local runtime. The latter checks exact
bilingual formulas, PDF bibliography URIs and renders every page. Reports,
compiler logs and source/PDF hashes are in `02_validation/v1.0/`.

The final rendered-page inspection and any report updates must precede
`python scripts/seal_sources.py`. `python scripts/verify_package.py` then
validates the final hashes without changing the package.

The current archive is `CDRIII_Lean_v1.0.zip`; its verified identity is in
`02_validation/v1.0/FREEZE.json`. The successful source-bound reconstruction is
documented in [CLEAN_REBUILD_PROTOCOL.md](CLEAN_REBUILD_PROTOCOL.md).

The two bilingual vector figures are generated by `scripts/make_explanatory_figures.py`
with Matplotlib. The script checks the trade incidence and circulation before
rendering; the convexity diagram is explicitly schematic.
